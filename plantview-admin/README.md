# PlantView Admin

Base arquitectónica de la consola exclusiva de MetKinetics. En esta etapa solo define navegación y límites; no conecta ni modifica Firebase, Firestore, clientes, usuarios, licencias o datos.

Los módulos críticos existentes permanecen sin cambios en sus archivos originales para una migración posterior controlada, pero ya no se cargan ni se muestran en el Dashboard del Cliente.
